# Test Repository

This is a test repository to be used for [sprintboard](https://github.com/BassamR14/js3-finalproject-sprintboard).

It exists only for testing how sprintboard displays issues labeled `to-do`, `ongoing`, and `completed`.

## Testing issue creation and editing

If you would like to test creating or editing issues, please ask the repository owner to deliver a fine-grained personal access token (PAT). The token will be valid for 7 days and scoped to this repository with permission to manage issues.
